COMSUP プライバシーポリシー

最終更新日: 2025年12月

COMSUP（以下「本アプリ」）は、ユーザーが地図上で位置情報やプロットを共有することを目的としたアプリです。
本アプリでは、ユーザーのプライバシーを尊重し、以下の方針に基づいて情報を取り扱います。

1. 収集する情報

1.1 位置情報（GPS）

本アプリは以下の目的で、端末の位置情報（緯度・経度・精度）を取得します。

  • 現在地の表示
  • A/B 2点校正（地図上の位置補正）
  • 自動追尾機能の提供（オプション）

位置情報は、ユーザーが端末の位置情報権限を許可した場合にのみ取得されます。
また、現在地マーカーはローカル表示に利用され、ルーム内の同期データとしてサーバーに送信されることはありません。

1.2 画像データ（地図画像）

ユーザーが選択した地図画像は、ルーム共有のために Firebase Storage に保存されます。
保存時には、AES-GCM による暗号化（IV + 暗号データ）を行い、安全に保存します。

暗号鍵は、ルームIDと固定ソルトから生成され、本アプリ内でのみ使用されます。

1.3 プロット（マーカー）情報

地図上にユーザーが追加したプロット（マーカー）の情報は、ルーム内共有のために Firebase Realtime Database に保存されます。

保存される主な情報は以下のとおりです。

  • プロットの位置（正規化された座標）
  • 色・形状・サイズ
  • メモとして入力されたテキスト
  • 任意で添付された画像（写真）

2. 使用する外部サービス

本アプリは、以下の外部サービスを利用します。

  • Google Firebase Realtime Database
  • Google Firebase Storage

これらのサービスにより、地図データやプロット情報が保存・同期されます。
Firebase が自動的に取得する可能性のある情報（IP アドレス、デバイス情報等）については、 Firebase のプライバシーポリシーに従います。

Firebase プライバシーポリシー:
https://firebase.google.com/support/privacy

3. 個人を特定できる情報について

本アプリは、以下の個人情報を収集しません。

  • 氏名
  • メールアドレス
  • 電話番号
  • 住所
  • アカウントID 等

端末識別に使用される情報（例：Android ID）は、ルームマスター機能の判定など、 本アプリ内の機能提供に限って利用され、第三者へ提供されることはありません。

4. データの利用目的

収集した情報は、以下の目的でのみ利用します。

  • 地図情報およびプロット情報の共有・表示
  • 位置補正および自動追尾機能の提供
  • アプリの品質向上のための匿名データ分析

これらの目的以外で情報を利用することはありません。

5. 第三者提供について

ユーザーの情報を、次の場合を除き第三者に提供することはありません。

  • 法令に基づく開示要請があった場合
  • 犯罪捜査等の協力要請が法的に有効な形で行われた場合

6. データの保存期間

  • Firebase に保存されたルームデータ（地図・プロット等）は、ルームが存在する限り保存されます。
  • 利用されなくなったルームは、Firebase の仕様や運用方針により一定期間後に削除される場合があります。
  • 端末内に保存されているデータ（ローカル地図、設定など）は、ユーザーがアプリをアンインストールした時点で削除されます。

7. ユーザーの権利

ユーザーは、以下を依頼することができます。

  • 保存されているデータの削除
  • 今後の利用停止の要請

これらの依頼は、下記お問い合わせ先にご連絡ください。

8. セキュリティ対策

本アプリでは、以下のようなセキュリティ対策を講じています。

  • 地図画像の AES-GCM 暗号化保存
  • Firebase Realtime Database / Storage のセキュリティルール設定
  • 必要最小限の権限のみを要求（位置情報、ストレージアクセス等）
  • アプリ内での誤操作防止（削除時の確認等）

9. プライバシーポリシーの変更

本ポリシーの内容は、必要に応じて変更される場合があります。
重要な変更がある場合は、アプリ内での告知またはストアの説明欄等でお知らせします。
